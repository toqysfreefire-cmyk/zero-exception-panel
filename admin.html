⚡ Vercel Instant Sync Engine

How changes you make in this admin page instantly appear on your Vercel live website for all customers worldwide.

🚀 Why Changes in Chrome Aren't Live Everywhere Yet:
Vercel serves pre-built static files from its global Edge CDN network, so browser edits save to your local browser storage by default. To make updates appear instantly (within 1 second) for every visitor worldwide without redeploying, connect your catalog to a free real-time cloud store (Firebase Firestore). Alternatively, download the updated products.json and push to GitHub (Vercel auto-deploys in 15 seconds).

Firebase Firestore Cloud Database (Recommended — 0s Realtime)

100% Free forever (50,000 reads/day). Changes in Admin update all customers' screens in 1 second.

Not Connected
Quick 2-Minute Setup:
1. Go to console.firebase.google.com and click Create a project.
2. In the left menu, click Build > Firestore Database, click Create database, and select Start in test mode.
3. Click the ⚙️ gear icon next to Project Overview > Project Settings > Under "Your apps" click Web (</>) > Copy your apiKey and projectId.
4. Paste them above and click Connect & Save. Done! All updates will sync automatically to every user worldwide.
